# Declare-ja
Declare Já é uma aplicação de estudo desenvolvida no Microsoft Excel
com o objetivo de ajudar a organizar e reunir informações importantes
para a preparação da declaração do Imposto de Renda.
A proposta é transformar a planilha em um ponto central de consulta, no
qual o usuário possa registrar dados pessoais, reunir informações de
rendimentos e manter referências úteis em uma estrutura organizada, com
recursos de validação e navegação.
Importante: este projeto tem finalidade educacional e de
organização de informações. Ele não substitui o programa oficial da
Receita Federal, a conferência dos documentos originais ou a
orientação de um profissional contábil. Os dados de exemplo presentes
na planilha são fictícios e devem ser substituídos pelos dados
corretos antes de qualquer uso real.

Objetivos do projeto
- Organizar os dados cadastrais do titular em um único local.
- Reunir informações de informes de rendimentos e instituições
  bancárias.
- Registrar entradas financeiras, como valores provenientes de
  holerites ou extratos.
- Facilitar o preenchimento e a conferência das informações por meio
  de uma interface simples.
- Aplicar conhecimentos de Excel, organização de dados, fórmulas e
  validação de informações.
- Evoluir a planilha gradualmente, incorporando funcionalidades que
  tornem o uso mais prático e confiável.
Estrutura da planilha
O arquivo Excel está organizado nas seguintes abas:
1. TITULAR
Área destinada aos dados cadastrais do contribuinte, incluindo:
- Nome e CPF;
- Data de nascimento e título de eleitor;
- Cônjuge;
- Endereço e CEP;
- Telefone, celular e e-mail;
- Informações complementares, como alterações em relação à entrega
  anterior, dependente cônjuge e residência no exterior.
2. INFORMES
Área para centralizar informações de informes de rendimentos de
instituições financeiras. A estrutura inclui:
- Instituição bancária;
- Valor atual informado;
- Referência ao documento ou anexo correspondente;
- Campo de totalização dos valores cadastrados.
A intenção é facilitar a consulta aos dados e a localização dos
documentos que servem de fonte para o preenchimento da declaração.
3. NOTAS
Área para registrar entradas financeiras com data, categoria e valor. A
estrutura atual permite organizar lançamentos, como valores
identificados em holerites ou extratos, para consulta e conferência
posterior.
4. REF BANCOS
Lista de referência com nomes e códigos de instituições financeiras.
Essa base pode apoiar listas suspensas e validações de dados em outras
abas, ajudando a padronizar os registros e reduzir diferenças na
digitação dos nomes dos bancos.
Recursos utilizados
O projeto foi desenvolvido no Excel e utiliza recursos de planilha para
estruturar e organizar as informações, incluindo:
- Fórmulas para totalização de valores;
- Listas de referência para instituições financeiras;
- Campos padronizados para entrada de dados;
- Organização por abas, separando cadastro, informes, lançamentos e
  referências;
- Estrutura preparada para receber melhorias de navegação, validação e
  usabilidade.
Como utilizar
1. Baixe ou clone este repositório.
2. Abra o arquivo
   DECLARE JÁ-APP PARA CALCULO DO IMPOSTO DE RENDA.xlsx em uma versão
   compatível do Microsoft Excel.
3. Confira as abas disponíveis e substitua os dados de exemplo por
   informações apropriadas para o seu cenário de teste.
4. Registre os dados cadastrais na aba TITULAR.
5. Cadastre as informações dos informes bancários na aba INFORMES,
   consultando os documentos originais.
6. Utilize a aba NOTAS para organizar entradas financeiras
   relevantes.
7. Consulte a aba REF BANCOS como base de referência para
   instituições financeiras.
8. Revise os registros e compare-os com os documentos de origem antes
   de utilizá-los em qualquer processo de declaração.
Cuidados com os dados
Informações como CPF, endereço, telefone, dados bancários e rendimentos
são dados pessoais e financeiros. Para proteger a privacidade:
- Utilize dados fictícios em demonstrações, testes e capturas de tela;
- Não publique planilhas com informações reais em repositórios
  públicos;
- Mantenha cópias de segurança em local seguro;
- Confira os valores e documentos de origem antes de utilizar os
  registros;
- Não considere os totais da planilha como validação fiscal ou como
  cálculo oficial do imposto devido.
Possíveis melhorias futuras
- Criar um menu inicial com links para navegação entre as abas;
- Ampliar as validações automáticas e as listas suspensas;
- Incluir atalhos para documentos e links úteis;
- Criar indicadores de preenchimento e alertas para campos pendentes;
- Organizar categorias adicionais de rendimentos, bens, direitos,
  pagamentos e deduções;
- Desenvolver um painel-resumo para acompanhar os dados cadastrados;
- Automatizar verificações de consistência e facilitar a conferência

- Melhorar a experiência visual para tornar o preenchimento mais
  intuitivo.
Tecnologias
- Microsoft Excel
- Fórmulas e recursos nativos de planilhas
- Validação e organização de dados
Finalidade educacional
O Declare Já é um projeto prático para exercitar o uso do Excel na
criação de uma ferramenta de organização de dados. O desenvolvimento
pode evoluir conforme novos conceitos forem estudados e novas
funcionalidades forem implementadas.
Projeto independente para fins de estudo. Não é um produto oficial da
Receita Federal e não oferece, por si só, garantia de conformidade
tributária.
